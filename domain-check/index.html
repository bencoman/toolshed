Call it from a URL

Put the names and endings in the query string and the check runs on load:

?q=mathforge,numberly&tld=com,com.au,au
  • q — names, comma separated. Bare words get every ending in tld; anything containing a dot is checked as typed.
  • tld — endings, comma separated. Leave it out for com,com.au,au.

The report's first line reads DOMAIN-CHECK DONE n/n once every lookup has finished (RUNNING before that); #report carries the same state in data-state, and window.toolshed holds the result as JSON. One status word per line: AVAILABLE, TAKEN, LIKELY-FREE, TAKEN-DNS, CHECK, UNKNOWN, INVALID. Follows the toolshed convention.

How it decides
  • Taken — the registry's RDAP server returned a record. Registrar and expiry come from that record.
  • Available — the registry's RDAP server answered 404 for the name. This is the strongest "free" signal a public lookup gives.
  • Likely free / Taken (DNS) — no usable RDAP answer for that ending (no server listed, blocked, or rate limited), so the call rests on DNS alone: NXDOMAIN suggests free, delegated name servers mean taken.
  • Check — RDAP and DNS disagree. Look it up at a registrar before deciding.
  • Unknown — neither lookup gave an answer. Usually a rate limit; wait a minute and re-run those rows.

Available at the registry does not always mean buyable at the standard price. Registries hold back reserved and premium names, and .au names carry eligibility rules (an Australian presence, and for com.au an ABN or ACN plus a connection to the name).

Lookups: RDAP servers from the IANA bootstrap list (rdap.org as the fallback redirector, throttled to its 10 requests per 10 seconds), .au via auDA's server, DNS over HTTPS from Google Public DNS with Cloudflare as fallback. Nothing else leaves the browser; the last run is kept in this browser's local storage only.

Four lookups run at a time. Runs are capped at 60 domains to stay under registry rate limits.
